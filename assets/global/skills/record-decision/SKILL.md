---
name: record-decision
description: Create or update an ADR and a linked Obsidian decision note for a significant technical decision.
---

1. Search for an existing ADR or equivalent vault note first.
2. Record context, options, decision, rationale, trade-offs, consequences, and reversal conditions.
3. Keep the repository ADR as the implementation source of truth.
4. Create a vault note only for durable or cross-session knowledge, linking to the repository ADR.
5. Never duplicate the full ADR in two places.
