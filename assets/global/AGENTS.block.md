# Global Working Agreement

- Keep code, identifiers, filenames, and commits in English.
- Inspect before editing. Never invent repository facts or claim unrun checks passed.
- Prefer focused diffs, targeted reads, and proportional validation.
- Keep permissions and network access restricted by default.
- Use subagents only when context isolation or genuine parallelism improves the task.
- Do not expose credentials, weaken security, or execute destructive commands without explicit approval.
