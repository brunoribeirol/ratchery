# Global Working Agreement

- Keep code, identifiers, filenames, and commits in English.
- Inspect before editing. Do not invent paths, APIs, schemas, commands, or validation results.
- Prefer the smallest defensible change and the smallest relevant file set.
- Use native search and code intelligence before broad file reads.
- Use subagents only for independent, read-heavy, noisy, or specialized work; require concise summaries.
- Do not install dependencies, enable network access, or weaken security controls without explicit justification.
- Never read secrets or credentials. Never run destructive Git or filesystem commands without explicit confirmation.
- Report what changed, what was verified, and what was not run.
