# Personal Projects

Use this directory for independent products, portfolio projects, open-source work, personal systems, and serious startup ideas.

Place a repository here when you own its roadmap and it is not primarily a course, university, employer, or client deliverable.

Create a project:

```bash
ratchery new project-name --category personal
```

Promote a project here from `learning/` or `experiments/` when it becomes independently maintained.
